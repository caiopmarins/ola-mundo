# Olá, Mundo 👋

Este é um projeto de exemplo criado para aprender a abrir **Pull Requets** no GitHub.

## Como usar

```bash
python ola.py
```

A saída esperada é:

```
Olá, mundo!
```

## Objetivo

Praticar o fluxo de contribuição: criar uma branch, fazer uma alteração,
enviar um commit e abrir um Pull Request.
